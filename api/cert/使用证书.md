# 生成证书
1. 生成私钥
```bash
openssl genpkey -algorithm RSA -out private.key -pkeyopt rsa_keygen_bits:2048
```
2. 生成证书签名请求(CSR)
```bash
openssl req -new -key private.key -out request.csr
```

系统会提示输入国家、组织等信息

3. 生成自签名证书
```bash
openssl x509 -req -days 365 -in request.csr -signkey private.key -out certificate.pem
```

4. 合并为PEM文件
```bash
cat private.key certificate.pem > combined.pem
```

5. 获取CERTIFICATE_THUMBPRINT环境变量
``bash
openssl x509 -in certificate.pem -fingerprint -noout
```
返回：
```bash
SHA1 Fingerprint=55:C0:40****
```
CERTIFICATE_THUMBPRINT为去掉冒号的Fingerprint

CERTIFICATE_THUMBPRINT=55C040****

# Azure以及项目配置操作

1. 上传生成的certificate.pem（公钥）到azure

2. 使用combined.pem（私钥）文件路径：translation_api/cert/combined.pen

3. 环境变量  AAD_PRIVATE_KEY_FILE=combined.pem
